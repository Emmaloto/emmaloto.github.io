## Contents

In addition to the website, the repo also contains certain submodules with my other repos.

* apps/SewaneeProfessor
* apps/WalkingStickBug
* apps/WebApplications
* apps/WebGraphics
* apps/mapping-game

To update submodules, you can run the following:

```bash
git submodule update --remote
git add apps/...
git commit -m "Update submodules"
```
